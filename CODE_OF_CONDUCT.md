# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies to every project space: issues, pull requests, discussions and reviews.

## Reporting

Report unacceptable behavior to the maintainer, [@Mmodarre](https://github.com/Mmodarre), using
the contact options on the maintainer's GitHub profile. Content on GitHub (comments, issues, pull
requests) can also be reported to GitHub with
[report content](https://docs.github.com/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).
Reports are handled confidentially, and enforcement follows the Contributor Covenant's
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
